# Watch Party ❤️🎬

یک سایت ساده و عاشقانه برای اینکه تو و پارتنرت با هم و همزمان فیلم ببینید.
کاملاً Static است و روی GitHub Pages اجرا می‌شود، بدون نیاز به سرور یا Backend جداگانه.

فایل‌های پروژه:
- `index.html`
- `style.css`
- `script.js`
- `README.md`

---

## مرحله ۱: ساخت Repository در GitHub

1. وارد [github.com](https://github.com) شو و اگر اکانت نداری، یکی بساز.
2. روی علامت **+** بالای صفحه بزن و **New repository** رو انتخاب کن.
3. یک اسم بذار، مثلاً: `watch-party`
4. حالت را روی **Public** بذار.
5. روی **Create repository** بزن.

---

## مرحله ۲: آپلود فایل‌ها

1. داخل صفحه‌ی Repository که ساختی، روی **Add file** بزن و **Upload files** رو انتخاب کن.
2. چهار فایل `index.html`، `style.css`، `script.js` و `README.md` رو انتخاب و آپلود کن.
   (با گوشی هم می‌تونی از داخل مرورگر فایل‌ها رو انتخاب کنی.)
3. پایین صفحه روی **Commit changes** بزن.

---

## مرحله ۳: فعال کردن GitHub Pages

1. داخل Repository، برو به تب **Settings**.
2. از منوی سمت چپ روی **Pages** بزن.
3. زیر بخش **Build and deployment** → **Branch**، گزینه‌ی `main` و پوشه‌ی `/(root)` رو انتخاب کن.
4. روی **Save** بزن.
5. چند دقیقه صبر کن، بعد بالای همون صفحه یک لینک به این شکل ظاهر می‌شه:

```
https://username.github.io/watch-party/
```

این لینک، آدرس آنلاین سایت توئه. (به‌جای username اسم اکانت خودت میاد)

---

## مرحله ۴: وصل کردن Firebase (برای همگام‌سازی فیلم)

برای اینکه Play، Pause و زمان فیلم بین تو و پارتنرت همزمان بشه، از یک دیتابیس رایگان به اسم **Firebase Realtime Database** استفاده می‌کنیم.

### ساخت پروژه‌ی Firebase

1. برو به [console.firebase.google.com](https://console.firebase.google.com)
2. روی **Add project** (یا **Create a project**) بزن.
3. یک اسم بذار (مثلاً `watch-party`) و مراحل رو تا آخر با گزینه‌های پیش‌فرض جلو برو.

### فعال کردن Realtime Database

1. داخل پروژه‌ات، از منوی سمت چپ **Build** → **Realtime Database** رو انتخاب کن.
2. روی **Create Database** بزن.
3. یک لوکیشن انتخاب کن و بعد گزینه‌ی **Start in test mode** رو بزن، بعد **Enable**.

> ⚠️ حالت **test mode** یعنی هرکسی می‌تونه بخونه و بنویسه. برای یک پروژه‌ی شخصی و کوچیک مثل این مشکلی نیست، ولی این حالت بعد از ۳۰ روز غیرفعال می‌شه. اگر بعد از ۳۰ روز سایت کار نکرد، کافیه دوباره به تب **Rules** بری و دسترسی read/write رو `true` بذاری.

### گرفتن Config پروژه

1. روی چرخ‌دنده‌ی کنار **Project Overview** (بالای منوی سمت چپ) بزن و **Project settings** رو انتخاب کن.
2. پایین صفحه، بخش **Your apps** رو پیدا کن و روی آیکون وب `</>` بزن تا یک وب‌اپ بسازی.
3. یک اسم دلخواه بده و **Register app** رو بزن.
4. یک کد شبیه این نمایش داده می‌شه:

```js
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  databaseURL: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

### جایگذاری Config در سایت

1. برگرد به Repository خودت روی GitHub.
2. فایل `script.js` رو باز کن و روی آیکون مداد (Edit) بزن.
3. مقدار `firebaseConfig` بالای فایل رو با مقداری که از Firebase کپی کردی جایگزین کن.
4. پایین صفحه روی **Commit changes** بزن.

بعد از چند ثانیه سایتت خودکار آپدیت می‌شه (نیازی به کار اضافه نیست).

## مرحله ۵: استفاده از سایت

1. لینک سایتت رو باز کن: `https://username.github.io/watch-party/`
2. روی دکمه‌ی «بریم فیلم ببینیم 🎬» بزن.
3. لینک مستقیم فیلم (مثلاً یک فایل `.mp4`) رو وارد کن و Room بساز.
4. لینک دعوتی که نشون داده می‌شه رو کپی کن و برای پارتنرت بفرست.
5. وقتی پارتنرت لینک رو باز کنه و دکمه‌ی «بریم فیلم ببینیم» رو بزنه، مستقیم وارد همون Room میشه، بدون اینکه نیاز باشه دوباره لینک فیلم رو وارد کنه.
6. حالا هر کدومتون Play/Pause یا جابه‌جا کنید، برای اون یکی هم همزمان می‌شه. 🎬❤️

---

## نکته درباره‌ی لینک فیلم

لینک باید یک لینک **مستقیم فایل ویدیو** باشد (معمولاً با پسوند `.mp4`) که مرورگر بتونه مستقیم پخشش کنه. لینک‌های صفحاتی مثل یوتیوب یا آپارات به این شکل کار نمی‌کنند.

---

## نکته درباره‌ی زیرنویس

دو راه برای اضافه‌کردن زیرنویس داری:

1. **لینک مستقیم زیرنویس (.vtt)**: موقع ساخت Room، توی فیلد «لینک زیرنویس» وارد کن. این زیرنویس برای پارتنرت هم خودکار لود می‌شه، دقیقاً مثل خود فیلم.
2. **آپلود فایل از گوشی (.srt یا .vtt)**: توی صفحه‌ی پخش فیلم، روی دکمه‌ی «افزودن زیرنویس از گوشی» بزن و فایل رو انتخاب کن. این حالت فقط روی گوشی خودت اعمال می‌شه (هرکس باید فایلش رو جدا اضافه کنه)، ولی چون به زمان پخش فیلم وصله، خودش با فیلم هماهنگ می‌مونه.

فایل‌های `.srt` به‌صورت خودکار به فرمت قابل‌پخش تبدیل می‌شن، نیازی به تبدیل دستی نیست.
